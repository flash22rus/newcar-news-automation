# План завершения NEWCAR News Automation

## Что уже работает в репозитории

- Ручной запуск GitHub Actions собирает свежие RSS-кандидаты.
- Анализ исключает материалы о внутреннем авторынке других стран.
- Похожие заголовки объединяются в одну новостную группу, а ссылки на публикации сохраняются для редактора.
- Google News ссылки по возможности раскрываются до страницы издателя.
- Отчёт показывает кандидаты, источники, публикации группы и ручные проверки.
- По умолчанию Workflow ничего не отправляет; создание черновиков включается отдельной опцией.
- Ежедневный сбор RSS запускается в 12:00 по времени Барнаула; создание черновиков по расписанию защищено отдельной Actions Variable.
- Draft-only этап поддерживает генерацию текста и картинки и интеграции Telegram Worker и Metricool.
- `publication_ready` и `fact_checking_complete` остаются `false`; отправка публикаций выключена.

## Целевая цепочка

1. Сбор RSS и редакционный отбор для российского рынка.
2. Проверка кандидатов поиском в интернете и подготовка редакционного текста отдельно для Telegram и Instagram.
3. Генерация изображения NEWCAR Premium Dark и загрузка в публичный Cloudflare R2.
4. Telegram Worker создаёт ожидающий черновик с четырьмя ссылками и подтверждением.
5. Metricool получает изображение и сохраняет Instagram пост как Draft; `autoPublish=false`.
6. Отдельно проверить источники, качество, секреты и устойчивость к повторам; после этого принимать решение о включении планирования и публикации.

## Что требуется для сквозной интеграции

### Настройка перед первым сквозным запуском

Список переменных и Secret приведён в README. Потребуется проверить доступность API Metricool на тарифе аккаунта, права ключа R2 и фактический URL Worker в настройках GitHub Actions. Значения не запрашиваются в чате и не хранятся в репозитории.

## Безопасный режим

Опция создания черновиков выключена по умолчанию. Draft этап требует четыре прямых HTTPS URL от разных издателей, изображения и настроенные API. Telegram Worker и Metricool переводятся в draft/pending состояния; `autoPublish` явно выключен. `fact_checking_complete` и `publication_ready` всегда ложны. Токены не записываются в отчёты или логи. Повторные попытки используют GitHub Actions cache и серверную идемпотентность Worker; перед повтором после сброса/истечения cache проверьте Draft в Metricool.
