# План завершения NEWCAR News Automation

## Что уже работает в репозитории

- Ручной запуск GitHub Actions собирает свежие RSS-кандидаты.
- Анализ исключает материалы о внутреннем авторынке других стран.
- Похожие заголовки объединяются в одну новостную группу, а ссылки на публикации сохраняются для редактора.
- Google News ссылки по возможности раскрываются до страницы издателя.
- Отчёт показывает кандидаты, источники, публикации группы и ручные проверки.
- `publication_ready` и `fact_checking_complete` остаются `false`; Workflow ничего не отправляет.

## Целевая цепочка

1. Сбор RSS и редакционный отбор для российского рынка.
2. Проверка первоисточника и независимых публикаций; автоматическая оценка не считается подтверждением факта.
3. Подготовка текста отдельно для Telegram и Instagram из подтверждённых данных.
4. Создание изображения NEWCAR Premium Dark и сохранение файла/публичного URL.
5. Telegram: передача текста, четырёх прямых ссылок и изображения в существующий NEWCAR News Draft 2.0 через его Worker; проверка превью перед публикацией.
6. Instagram: подготовка карусели/поста и передача в Metricool через разрешённую интеграцию.
7. Включение расписания и публикации только после сквозной проверки обоих каналов и явного переключения защитного флага.

## Что требуется для сквозной интеграции

### Telegram

Worker и API NEWCAR News Draft 2.0 не находятся в этом репозитории и не доступны в открытых локальных файлах. Нужны исходный код Worker либо опубликованный контракт endpoint: адрес, схема запроса, способ авторизации и ожидаемый ответ. Это необходимо, чтобы GitHub передавал черновик именно в существующий бот и не обходил CRM, KV и кнопки подтверждения.

### Изображения и генерация текста

Нужен выбранный API-провайдер генерации и отдельное хранилище или маршрут загрузки изображения, откуда Telegram Worker и Metricool смогут получить файл. Ключи хранятся только в GitHub Actions Secrets, а не в файлах репозитория.

### Instagram

Текущая публикация Instagram выполняется существующей автоматизацией Codex через Metricool. GitHub Actions не имеет доступа к инструментам Codex. Для единого GitHub-конвейера потребуется поддерживаемый Metricool API с credentials либо надёжный webhook/оркестратор между GitHub и существующей автоматизацией.

## Безопасный режим

До получения контрактов и прохождения сквозных тестов Workflow остаётся ручным и только формирует отчёты. Токены не записываются в отчёты или логи. Ни Telegram, ни Instagram не публикуются автоматически при пустом списке подтверждённых фактов, отсутствии изображения, недостатке источников или неуспешной проверке.
