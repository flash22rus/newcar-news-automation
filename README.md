
# NEWCAR Daily News

Проект для сбора кандидатов автомобильных новостей для NEWCAR.

## Цель

Подготовить безопасный и проверяемый процесс:

1. Найти свежие автомобильные новости.
2. Отобрать публикации за последние 24 часа.
3. Удалить дубли.
4. Проверить содержание и дату публикации.
5. Найти подтверждение в двух независимых источниках.
6. Подготовить текст новости и изображение в стиле NEWCAR Premium Dark.
7. Создать черновик для ручного одобрения.

## Текущий этап

Сейчас реализуется только сбор кандидатов через RSS.

На этом этапе программа:

- получает данные из RSS-лент;
- проверяет даты публикаций;
- отбирает свежие материалы;
- удаляет дубли;
- выводит JSON-отчёт.

Сборщик не публикует новости и не отправляет сообщения в Telegram.

## Требования

- GitHub Actions;
- Python 3.12;
- доступ к RSS-лентам из среды GitHub Actions.

Дополнительные Python-библиотеки на текущем этапе не требуются.

## Ручной запуск

1. Открой вкладку Actions.
2. Выбери NEWCAR Daily News.
3. Нажми Run workflow.
4. Открой последний запуск.
5. Разверни задание Collect recent news candidates.
6. Проверь вывод шага Collect RSS candidates.

## Критерии проверки

Успешный запуск GitHub Actions сам по себе не означает, что новости найдены.

Нужно проверить:

- сколько RSS-лент удалось загрузить;
- сколько публикаций найдено;
- сколько публикаций прошло проверку даты;
- есть ли ошибки загрузки;
- сколько уникальных кандидатов осталось.

Если все ленты недоступны, необходимо изучить причины ошибок.

## Безопасность

- Не хранить API-ключи и токены в исходном коде.
- Не публиковать новости автоматически.
- Не считать RSS-заголовок подтверждённым фактом.
- Не создавать черновик без проверки содержания и источников.
- Требовать ручного одобрения перед публикацией.
