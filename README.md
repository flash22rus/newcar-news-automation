# NEWCAR News Automation

Ежедневный поиск и проверка автомобильных новостей для NEWCAR с передачей черновиков в Telegram на ручное утверждение.

## Назначение

- Искать новости об импорте автомобилей в Россию, Японии, Китае, Южной Корее, утильсборе, таможне, логистике и ценах.
- Проверять дату публикации и подтверждать факты по двум независимым источникам.
- Не отправлять сомнительные или повторные материалы.
- Передавать подготовленный материал в существующий Cloudflare Worker через `/newsdraft`.
- Оставлять окончательное решение о публикации администратору NEWCAR.

## Безопасность

- Не хранить API-ключи, токены и секреты в исходном коде. 
- Использовать GitHub Actions Secrets для конфиденциальных значений.
- Не публиковать новости автоматически.
- Не изменять рабочую CRM и существующий Cron Cloudflare Worker.
- При отсутствии оригинального логотипа NEWCAR или подтверждения источников остановить отправку.

## Статус

Репозиторий создан. Автоматизация будет включена только после настройки файлов, секретов и успешной проверки тестового запуска.
